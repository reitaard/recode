# Recode Support

Recode is still being prepared as a standalone public repository. Product source, packages, binaries, public CI, and release channels are not yet certified here, so normal user support is not active.

After launch, use the following routing:

- **Bug:** a minimal reproducible issue with Recode version, installation method, operating system, terminal/runtime information, expected behavior, actual behavior, and sanitized logs.
- **Feature or design:** explain the use case and ownership boundary before proposing an implementation.
- **Documentation:** identify the owning file and the source/export/test evidence that conflicts with it.
- **Question:** use the approved discussion/support channel once enabled rather than filing an unverifiable bug.
- **Security:** do not disclose active vulnerabilities or secrets publicly. The private reporting channel and canonical `SECURITY.md` are pending approval; public support/contribution intake must remain closed until they are active.

Do not upload API keys, bot tokens, OAuth data, session transcripts, memory databases, private source, personal paths, or unredacted environment dumps. Reproduce with the smallest safe fixture.

The project does not promise response or release timelines. Experimental integrations, local models, external providers, Telegram, Maestro services, containers, Termux, and native binaries may require separate certification and may not be supported on every platform.
