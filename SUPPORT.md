# Recode Support

Use GitHub issues for reproducible bugs, feature proposals, and documentation problems. Use [SECURITY.md](SECURITY.md) for private vulnerability reporting.

Include the Recode version or commit, installation method, operating system, Node version, terminal/runtime information, expected behavior, actual behavior, and the smallest sanitized reproduction.

Do not upload API keys, bot tokens, OAuth data, session transcripts, memory databases, private source, personal paths, or unredacted environment dumps.

The project does not promise response, merge, support, or release timelines. Experimental integrations, local models, external providers, Telegram, Maestro services, containers, Termux, native addons, and uncertified platforms may require separate evidence and may not be supported.
