# About Recode

Recode is a coding harness derived from Pi and developed as its own product.

- **Aizen:** main coding agent and Manager
- **AgentHarness:** reusable model/tool runtime
- **Workers:** bounded specialists for research, audit, and knowledge work
- **Kioku, Shiori, Cardinal:** durable memory search, review, and admission
- **Maestro:** durable full-session supervision
- **LSP and tools:** code editing and intelligence
- **CLI/TUI:** primary local interface

## Rules

- Recode is the product; Pi is an integration source.
- Keep one reusable runtime and one Maestro supervisor.
- Use deterministic code for mechanical work and models for judgment.
- Load only task-relevant context and tools.
- Verify old claims against code, tests, Git, or runtime evidence.

This repository is the migration target, not yet the source authority. Unapproved product possibilities are kept separately in [Future Possibilities](FUTURE.md); they are not current features or commitments.
