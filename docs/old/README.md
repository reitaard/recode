# Old Recode Documents

Everything below this directory is historical source material copied from the older `re.pi` repository during the Recode repository migration.

## Rules

- Do not load this directory during normal work.
- Do not treat these files as current instructions.
- Expect stale paths, branch names, package states, plans, and incomplete features.
- Verify every consequential claim against current source, tests, Git state, or runtime evidence.
- Link to a specific old file only when a current document needs historical evidence.
- Do not edit old files merely to make them look current.
- Do not purge anything until its useful facts have been moved into current focused documents and the Creator approves removal.

## Layout

- `root/` — old root instructions and product documents
- `docs/` — old architecture and agent plans
- `Analyze/` — audits, roadmaps, checkpoints, and raw evidence
- `update/` — old updater context, decisions, plans, and logs
- `packages/orchestrator/` — old Maestro package docs and changelog
- `scripts/` — old platform instructions
- `migration/` — completed standalone transfer ledgers, inventories, plans, and manifest tooling
